## 🌟 প্রজেক্টের পরিচিতি (Overview)

**Royal History (রয়েল হিস্ট্রি)** হলো একটি সম্পূর্ণ স্বয়ংক্রিয় ঐতিহাসিক কার্ড জেনারেশন ও আর্কাইভ প্ল্যাটফর্ম। এটি প্রতিদিনের ক্যালেন্ডার তারিখ অনুযায়ী—
1. **📜 ইতিহাসের এই দিনে (On This Day in History):** সাধারণ আন্তর্জাতিক ও স্মরণীয় ঐতিহাসিক অধ্যায়।
2. **🇧🇩 বাংলাদেশ (Bangladesh History):** ভাষা আন্দোলন, মুক্তিযুদ্ধ, সংবিধান, জাতীয় অর্জন ও সূর্যসন্তানদের আত্মত্যাগ।
3. **🌍 বিশ্ব (World History):** বিশ্বযুদ্ধ, বিপ্লব, মহাকাশ অভিযান, বিজ্ঞান ও প্রযুক্তি এবং আন্তর্জাতিক সনদ।

এই ৩টি ক্যাটাগরি থেকে স্মার্ট রোটেশনের মাধ্যমে স্বয়ংক্রিয়ভাবে আকর্ষণীয় **১০৮০×১০৮০ পিক্সেল** সোশ্যাল মিডিয়া পোস্ট কার্ড তৈরি করে। 

* 🌐 **লাইভ ওয়েব ডিরেক্টরি:** [https://royal-technologies.github.io/Royal-History/](https://royal-technologies.github.io/Royal-History/)
* 🏷️ **প্রতিষ্ঠাতা ও কারিগরি সহায়তা:** [Royal Technologies](https://www.royaltechbd.com/)

এটি ফেসবুক, ইনস্টাগ্রাম, লিংকডইন, হোয়াটসঅ্যাপ চ্যানেল ও এক্স (টুইটার)-এ সরাসরি শিডিউল করার জন্য রেডি ক্যাপশন সহ `today.png` এবং `today.json` আউটপুট দেয়।

## ✨ মূল সুবিধাসমূহ (Key Features)

* 📅 **ক্যালেন্ডার ও ইভেন্ট-বেসড স্মার্ট সিলেকশন:**
  - প্রতিদিনের নির্দিষ্ট তারিখের (দিন ও মাস) সাথে মিলিয়ে স্বয়ংক্রিয়ভাবে প্রাসঙ্গিক ঐতিহাসিক ঘটনা বাছাই করে।
  - নির্দিষ্ট দিনে একাধিক ঘটনা থাকলে স্মার্ট রোটেশনের মাধ্যমে কম ব্যবহৃত (`used_count ASC`) ঘটনাকে প্রাধান্য দেওয়া হয়।
* 📜 **মাল্টি-ইভেন্ট কার্ড আর্কিটেকচার (Multi-Event Layout):**
  - কার্ডের শীর্ষে তারিখ হলো মূল হিরো ব্যানার (`📅 ৫ নভেম্বর — ইতিহাসের পাতায় আজকের দিন`)।
  - একই কার্ডে আজকের দিনের একাধিক (২–৩টি) ঐতিহাসিক ঘটনা সুন্দর রো আকারে সুষম ও শালীন সাল ব্যাজ (`[১৬০৫ খ্রিস্টাব্দ]`, `[১৯৭৪]`) সহ সাজানো হয়।
* 🎨 **২০০টি ভিন্ন ডিজাইনের জাদু (২০টি লেআউট আর্কিটেকচার × ১০টি রয়্যাল কালার থিম):**
  - **১০টি আর্কিটেকচারাল ফ্রেম:** মেহরাব আর্চ, রাজকীয় মিনিমাল, জ্যামিতিক রজেট ও মান্ডালা, প্রাচীন পাণ্ডুলিপি, অটোমান ইজনিক টাইলস, রাজকীয় স্তম্ভ ও তোরণ, হিলাল ও গ্যালাক্সি, আন্দালুসীয় আলহামব্রা, আটকোণা মেডেলিয়ন এবং কাবার গিলাফ স্বর্ণসূত্র ফিতা।
  - **১০টি শৈল্পিক সিনিক ব্যাকগ্রাউন্ড (ক্যানভাস আর্ট):** 
    1. *গোধূলি বেলার পাহাড় (Mountain Twilight)*
    2. *ভিন্টেজ কাবা পাণ্ডুলিপি (Kaaba Vintage Sketch)*
    3. *কাঠের রেহাল ও প্রাচীন গ্রন্থ স্টুডিও (Rehal Studio)*
    4. *তারকাময় মরুভূমি (Desert Dunes & Stars)*
    5. *সোনালী সূর্যাস্ত মেঘমালা (Golden Sunset Clouds)*
    6. *গোধূলি মনুমেন্ট ও গম্বুজ (Dome at Dusk)*
    7. *শ্যামলিম প্রাঙ্গণ (Emerald Sanctuary)*
    8. *শুভ্র আইভরি ও সোনা (Alabaster Minimal Gold)*
    9. *রক্তিম দামেস্ক দিগন্ত (Crimson Dusk Horizon)*
    10. *কাবার কালো রেশম (Kiswah Midnight Silk)*
  - **১০টি রয়্যাল কালার থিম (Royal Noor-এর মতো):** Royal Emerald, Midnight Navy, Imperial Black, Warm Parchment, Royal Maroon, Ottoman Turquoise, Desert Amber, Amethyst Violet, Andalusian Mihrab, Classic Ivory।
* 🔤 **নিখুঁত বাংলা টাইপোগ্রাফি ও জিরো গ্লিফ বক্স:**
  - খাঁটি ভেক্টর জ্যামিতি (`drawCompassRose`, `drawVintageCorner`, `drawLaurelBranch`) ব্যবহারের কারণে কোনো ডিভাইসে গ্লিফ বা বক্স (`□`) আসার সুযোগ নেই।
  - ফন্ট প্রদর্শনের জন্য অফলাইন **Hind Siliguri** ফন্ট সংকলিত।
* 📤 **সোশ্যাল শেয়ার ও ক্যাপশন ইঞ্জিন:**
  - এক ক্লিকে সম্পূর্ণ প্রস্তুত ক্যাপশন কপি (সাল, বিস্তারিত পটভূমি, ঐতিহাসিক গুরুত্ব, স্থান, তথ্যসূত্র ও হ্যাশট্যাগ সহ)।
  - মোবাইল ও ডেস্কটপে সরাসরি ইমেজ শেয়ার সুবিধা।
* 🛡️ **গিটহাব ৬০-দিনের ল্যাপস প্রিভেনশন (Keepalive Engine):**
  - গিটহাবের নিয়ম অনুযায়ী ৬০ দিন নিষ্ক্রিয় থাকলে ক্রন শিডিউলার বন্ধ হয়ে যায়। রয়েল হিস্ট্রিতে প্রতিদিনের অটো-কমিট ছাড়াও একটি ব্যাকআপ `keepalive.yml` রয়েছে যা প্রতি সপ্তাহে চেক করে ৬০ দিনের টাইমার স্বয়ংক্রিয়ভাবে রিসেট করে দেয়।
* 🌐 **মডার্ন ওয়েব ইন্টারফেস (`index.html`):**
  - তাৎক্ষণিক লাইভ সার্চ (শিরোনাম, সাল, কীওয়ার্ড)।
  - ক্যাটাগরি ফিল্টারিং (ইতিহাসের এই দিনে, বাংলাদেশ, বিশ্ব)।
  - মাসভিত্তিক ক্যালেন্ডার ড্রপডাউন এবং ইভেন্ট টাইপ ফিল্টার।
  - ডার্ক ও লাইট মোড টগল।
  - যেকোনো ঘটনার ১০৮০×১০৮০ ইমেজ ডাউনলোড।

## 🚀 লোকাল রান ও কমান্ডসমূহ (Commands)

### ১. লোকাল অ্যাডমিন ড্যাশবোর্ড ওপেন করা:
```bash
npm run admin
```
> এটি ব্রাউজারে `http://127.0.0.1:3400/admin.html` চালু করবে। এখান থেকে আপনি সরাসরি SQLite ডাটাবেজে নতুন ঐতিহাসিক ঘটনা যুক্ত, এডিট ও ডিলিট করতে পারবেন এবং যেকোনো কার্ড ইনস্ট্যান্ট টেস্ট করতে পারবেন।

### ২. আজকের কার্ড জেনারেট করা:
```bash
npm run generate
```

নির্দিষ্ট ক্যাটাগরি বা থিম দিয়ে টেস্ট করতে:
```bash
# শুধুমাত্র বাংলাদেশ ক্যাটাগরির কার্ড:
node scripts/generate-history.js --category=bangladesh

# শুধুমাত্র বিশ্ব ক্যাটাগরির কার্ড:
node scripts/generate-history.js --category=world

# নির্দিষ্ট থিমে কার্ড:
node scripts/generate-history.js --theme=independence-emerald
```

### ৩. ডাটাবেজ ইনিশিয়ালাইজ / রিসেট:
```bash
npm run init-db
```

## 📥 নতুন ঐতিহাসিক ঘটনা যুক্ত করার নিয়ম

গিটহাব বা লাইভ ওয়েব থেকে বহিরাগত কেউ ডাটাবেজ পরিবর্তন করতে পারবে না। শুধুমাত্র আপনি আপনার লোকালহোস্ট থেকে ডাটা যুক্ত করতে পারবেন:

### পদ্ধতি ১: লোকাল অ্যাডমিন প্যানেল থেকে (সবচেয়ে সহজ)
1. টার্মিনালে রান করুন:
   ```bash
   npm run admin
   ```
   (অথবা লারাগনে সরাসরি `http://localhost/Github/Royal%20History/admin.html` ওপেন করুন)
2. ফর্মে সাল, তারিখ, ক্যাটাগরি, শিরোনাম ও বিবরণ দিয়ে **"সংরক্ষণ করুন"** চাপুন।
3. সরাসরি আপনার লোকাল SQLite ডাটাবেজে যুক্ত হয়ে যাবে!

### ⏰ স্বয়ংক্রিয় আপডেট সময় ও শিডিউল পোস্টিং গাইডলাইন

গিটহাব অ্যাকশনসের মাধ্যমে ফাইল ২টি **প্রতিদিন সকাল ০৬:০৫ টায় (BST / 00:05 GMT)** স্বয়ংক্রিয়ভাবে নতুন ঘটনা ও ডিজাইনে আপডেট হয়।

| আপডেট স্লট | বাংলাদেশ সময় (BST / UTC+6) | আন্তর্জাতিক সময় (GMT / UTC) | অটোমেশন শিডিউল পোস্টিংয়ের আদর্শ সময় |
|:---|:---|:---|:---|
| **দৈনিক আপডেট** | **সকাল ০৬:০৫ টা** | **00:05 GMT** | **সকাল ০৮:০০ টা BST (02:00 GMT)** |

> [!TIP]
> **কেন সকাল ৮:০০ টায় শিডিউল করবেন?**  
> ফাইলটি সকাল ৬:০৫ টায় আপডেট সম্পন্ন হওয়ার পর **সকাল ৮:০০ টায়** সোশ্যাল মিডিয়ায় পোস্ট করলে (Facebook, Instagram, LinkedIn) সবচেয়ে বেশি রিচ ও এঙ্গেজমেন্ট পাওয়া যায়।
